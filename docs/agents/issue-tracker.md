# Issue tracker: GitHub

Repository: z1rass/GSO-engineering-lab.
Specs and tickets live in GitHub Issues. Use gh with explicit
--repo z1rass/GSO-engineering-lab.

Read issues with their labels and comments. Publish one issue per
spec or ticket. Pass multiline bodies through --body-file.

Record blocking dependencies using native GitHub issue dependencies
when available; otherwise use a "Blocked by" list of issue references.
Start a ticket only after its blockers are complete.

PRs as a request surface: no.

Local specification and ticket drafts remain drafts until published.
Use the label mapping in triage-labels.md.
