# 10: Going и повторное подтверждение при переносе

**What to build:** Owner открывает регистрацию, Member записывается, а перенос возвращает участника в Interested.

**Blocked by:** 07: Interested без регистрации; 09: Простой запрос помещения

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Going открывается при определённых дате, времени, месте и подтверждённом Room Request, когда помещение требуется.
- [ ] Event без потребности в школьном помещении открывает owner самостоятельно.
- [ ] Можно записаться и отказаться; нет лимита мест, листа ожидания и дублирования регистраций.
- [ ] Смена даты или времени переводит существующие Going в Interested без частичного обновления.
- [ ] Изменение описания не сбрасывает Going; перенос/отмена сообщаются вручную в Discord.
- [ ] Проверяются условия открытия, права, повторные действия, сброс регистрации и сохранение её при обычном редактировании.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
