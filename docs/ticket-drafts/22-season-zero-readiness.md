# 22: Сквозная готовность к Season 0

**What to build:** Новый contributor запускает MVP, а участники проходят согласованные сценарии Season 0.

**Blocked by:** 14: Seasons и продолжение Project; 18: Удаление профиля через Ops; 19: Восстановление Ops и handover; 21: Ежедневный backup и проверенный restore

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Seed содержит Season 0, два Projects, три Events, пять Users и десять Tasks; данные безопасны для локальной разработки.
- [ ] README покрывает запуск, конфигурацию, миграции, тесты, contribution и PR flow.
- [ ] Браузерные проверки проходят discovery/login/join, Idea → Activity, Take → My Activity, Room Request → Going и переключение DE/EN на mobile.
- [ ] CI проверяет types, lint, tests и build; обязательные проверки предотвращают merge сломанной сборки.
- [ ] Проверены moderation, closure, transfer, profile deletion и recovery по ранее реализованным контрактам.
- [ ] Повторён restore с финальной схемой и проверено, что удалённые персональные данные не возвращаются в рабочую систему.
- [ ] Отдельный вход Alumni, Discord-бот, автоматические уведомления об Activity и загрузки файлов отсутствуют; выявленные дефекты фиксируются отдельно.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
