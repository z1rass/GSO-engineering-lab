# 08: Вступление в команду Project

**What to build:** Member присоединяется к Project и может выйти из команды.

**Blocked by:** 05: Создание Project с owner

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Join работает сразу, без заявок и Ops approval, в том числе на этапе подготовки.
- [ ] Команда и счётчик обновляются; повторный Join не дублирует участника.
- [ ] Leave удаляет участие, но не уничтожает историю и не освобождает автоматически ownership.
- [ ] Activity Owner не может обойти передачу ответственности обычным Leave.
- [ ] Visitors видят допустимые публичные данные; список людей доступен только Members.
- [ ] Проверяются join/leave, повторные действия, прямые неавторизованные запросы и сохранение owner.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
