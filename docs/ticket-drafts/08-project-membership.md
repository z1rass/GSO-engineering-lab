# 08: Вступление в команду Project

**What to build:** Member присоединяется к Project и может выйти из команды.

**Blocked by:** 05: Создание Project с owner

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано локально 2026-09-22.

## Acceptance criteria

- [x] Join работает сразу, без заявок и Ops approval, в том числе на этапе подготовки.
- [x] Команда и счётчик обновляются; повторный Join не дублирует участника.
- [x] Leave удаляет участие, но не уничтожает историю и не освобождает автоматически ownership.
- [x] Activity Owner не может обойти передачу ответственности обычным Leave.
- [x] Visitors видят допустимые публичные данные; список людей доступен только Members.
- [x] Проверяются join/leave, повторные действия, прямые неавторизованные запросы и сохранение owner.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.



## Результат

Join/Leave доступны на странице Project с DE/EN. PLANNING и ACTIVE принимают участников сразу; закрытые проекты не принимают Join. Owner и участие различаются: создание Project не добавляет owner в счётчик команды автоматически; owner может вступить явно, но Leave возвращает 409 до передачи ответственности.

В project_memberships сохраняются периоды участия: Leave закрывает текущий период, повторный Join создаёт новый. Уникальный индекс запрещает дубликаты открытого периода. Операции выполняются с блокировкой строки Project в транзакции. Visitors получают только количество, Members — имена текущей команды и собственную историю без email.

Interested не меняется при Join/Leave и не создаёт участие. Членство не даёт права редактировать, Leave не меняет owner. Task ownership и передача ответственности остаются следующими задачами.
