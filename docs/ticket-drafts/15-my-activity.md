# 15: Личный обзор участия и ответственности

**What to build:** Member открывает My Activity и понимает, где участвует и за что отвечает.

**Blocked by:** 07: Interested без регистрации; 08: Вступление в команду Project; 10: Going и повторное подтверждение при переносе; 11: Взять, завершить и освободить Task

**Status:** реализовано локально 2026-09-22; draft не опубликован в GitHub.

## Acceptance criteria

- [x] Есть свои Projects, Events и Tasks; Activity ownership показан явно.
- [x] Interested различим с Going и Project membership; отметка интереса не выглядит обязательством.
- [x] После взятия/освобождения задачи, выхода из команды или принятия передачи обзор отражает сохранённое состояние.
- [x] Данные доступны только текущему User; попытка получить чужой личный обзор отклоняется.
- [x] Проверены DE/EN и мобильная компоновка; браузерный сценарий Take → My Activity показывает задачу.

## Проверка и границы

Использованы ранее согласованные границы: HTTP API с настоящей изолированной PostgreSQL и браузерный сценарий. Проверки наблюдают сохранённое поведение через публичные интерфейсы. Интерфейс доступен на DE/EN; авторский контент не переводится.

## Результат

`/my-activity` доступен через «Mein Lab / My Lab» и профиль. Текущие Tasks показаны первыми; Projects/Events разделяют ownership, Project membership и Going. Interested для Ideas и Activity находится в отдельной секции с пояснением, что это не участие. Завершённые/отменённые Activity и Tasks остаются в раскрываемой истории.

`GET /api/me/activity` получает User только из сессии, отклоняет query-параметры и возвращает `no-store`. Все секции читаются одним SQL statement из существующих таблиц; миграция и дублирование состояния не нужны. При возвращении на страницу обзор загружается заново, поэтому показывает release, leave, принятую передачу и сброс Going после переноса Event. Чужого адресуемого обзора нет.

Проверки: typecheck, lint, build; 61 API/CLI test и 20 браузерных сценариев прошли. Desktop/mobile проверены визуально. Review по Standards и Spec — без замечаний.
