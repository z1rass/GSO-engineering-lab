# 15: Личный обзор участия и ответственности

**What to build:** Member открывает My Activity и понимает, где участвует и за что отвечает.

**Blocked by:** 07: Interested без регистрации; 08: Вступление в команду Project; 10: Going и повторное подтверждение при переносе; 11: Взять, завершить и освободить Task

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Есть свои Projects, Events и Tasks; Activity ownership показан явно.
- [ ] Interested различим с Going и Project membership; отметка интереса не выглядит обязательством.
- [ ] После взятия/освобождения задачи, выхода из команды или принятия передачи обзор отражает сохранённое состояние.
- [ ] Данные доступны только текущему User; попытка получить чужой личный обзор отклоняется.
- [ ] Проверены DE/EN и мобильная компоновка; браузерный сценарий Take → My Activity показывает задачу.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
