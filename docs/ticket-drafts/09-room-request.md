# 09: Простой запрос помещения

**What to build:** Owner просит помещение, Ops подтверждают условия либо предлагают ближайший вариант.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано локально 2026-09-22.

## Acceptance criteria

- [x] Форма запроса и очередь Ops работают для Activity; Member не делает запрос от имени чужой Activity.
- [x] Ops сохраняют подтверждение или доступную альтернативу; owner видит ответ.
- [x] Предложение альтернативы не выглядит автоматически подтверждённой договорённостью.
- [x] Подтверждение независимо от жизненного цикла Activity; до него можно продолжать подготовку.
- [x] Нет оборудования, каталога ресурсов или отзыва подтверждения: подтверждение окончательно по допущению MVP.
- [x] API/UI проверки подтверждают права и различие ожидаемых и подтверждённых условий.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Owner отправляет пожелания на странице Event/Project; одна Activity имеет один запрос. Очередь Ops доступна через /ops/rooms. Ops предлагают альтернативу или явно подтверждают структурированные дату, время и комнату. Альтернативу согласуют вручную через Discord; она остаётся ALTERNATIVE до отдельного подтверждения Ops. Финальное подтверждение неизменяемо через API.

Публичен только статус. Текущие Members видят подтверждённые условия и комнату; пожелания, альтернативы и ответ Ops доступны только owner/Ops. Интерфейс DE/EN. Слот относится к Europe/Berlin и допускает несколько дней. Activity продолжает подготовку независимо от запроса; подтверждение не меняет план Event и не открывает Going. При реализации Going необходимо сравнивать его условия с подтверждённым слотом.
