# 09: Простой запрос помещения

**What to build:** Owner просит помещение, Ops подтверждают условия либо предлагают ближайший вариант.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Форма запроса и очередь Ops работают для Activity; Member не делает запрос от имени чужой Activity.
- [ ] Ops сохраняют подтверждение или доступную альтернативу; owner видит ответ.
- [ ] Предложение альтернативы не выглядит автоматически подтверждённой договорённостью.
- [ ] Подтверждение независимо от жизненного цикла Activity; до него можно продолжать подготовку.
- [ ] Нет оборудования, каталога ресурсов или отзыва подтверждения: подтверждение окончательно по допущению MVP.
- [ ] API/UI проверки подтверждают права и различие ожидаемых и подтверждённых условий.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
