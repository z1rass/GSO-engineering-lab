# 21: Ежедневный backup и проверенный restore

**What to build:** Оператор восстанавливает данные из автоматического backup в отдельной среде.

**Blocked by:** 20: Доступный production-контур

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Настроен ежедневный backup PostgreSQL; выбраны назначение и срок хранения.
- [ ] Процедура восстановления воспроизводима и выполнялась на отдельной базе.
- [ ] Проверяется содержимое восстановленных данных и работоспособность приложения, а не только наличие файла.
- [ ] Права на backup ограничены, чувствительные данные и секреты не раскрываются в логах.
- [ ] Согласована обработка удаления персональных данных после восстановления; контроль повторён в финальной проверке.
- [ ] Документированы выполнение и результат восстановления.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решения до реализации

Нужны backup destination/retention и доступы; процедура удаления должна быть совместима с задачей 18.
