# 16: Приватный Club Network

**What to build:** Ops сохраняют и обновляют контакты клуба для будущих приглашений.

**Blocked by:** 03: Первичные Ops и обычное назначение

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Ops могут создавать, читать, редактировать и удалять записи контактов.
- [ ] Контакт поддерживает имя, компанию, профессиональную роль, темы, заметки, способ связи и происхождение записи.
- [ ] Visitor и Member не получают записи или contact emails ни прямым API, ни через публичные страницы.
- [ ] Member обращается за помощью к Ops через Discord; отдельная система запросов не появляется.
- [ ] Проверки матрицы доступа и persisted CRUD защищают базу от утечек.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
