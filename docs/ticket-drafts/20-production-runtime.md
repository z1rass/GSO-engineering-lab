# 20: Доступный production-контур

**What to build:** Оператор разворачивает текущие готовые сценарии в Docker с HTTPS и проверяет вход.

**Blocked by:** 02: Magic link и минимальный профиль

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Задокументированы выбранные hosting, domain, reverse proxy и владельцы эксплуатационных доступов.
- [ ] Frontend/API доступны через HTTPS; PostgreSQL недоступна напрямую из Internet; секреты не включены в исходники.
- [ ] Действуют необходимые cookie/CSRF настройки и production email delivery для magic link.
- [ ] Есть application/proxy logs и health endpoint без утечки секретов.
- [ ] Проверены deploy, миграции и реальный smoke-сценарий открытия сайта/входа; существующий CI продолжает проходить.
- [ ] Это проверяемый эксплуатационный срез текущего приложения, не заявление о готовности всех остальных функций.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решения до реализации

Нужны выбор инфраструктуры, домена, почтовой доставки и реальные доступы; не считать их уже согласованными.
