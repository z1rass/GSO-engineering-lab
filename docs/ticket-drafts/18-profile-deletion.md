# 18: Удаление профиля через Ops

**What to build:** Ops выполняют запрос удаления, сохранив результаты без персональной идентичности.

**Blocked by:** 13: Завершение, отмена и прошедшие; 15: Личный обзор участия и ответственности; 16: Приватный Club Network; 17: Скрытие контента и блокировка User

**Status:** implemented locally 2026-09-22 — draft not published.

## Acceptance criteria

- [x] Активное ownership сначала передаётся или отменяется; удаление не оставляет активную Activity без ответственности.
- [x] Профиль и связанные персональные данные удаляются, сессии перестают работать.
- [x] Неперсональные результаты сохраняются с подписью «Удалённый участник», а не старым именем/email.
- [x] Учтены participation, задачи, истории назначений и attribution записей Club Network без удаления чужих независимых контактов.
- [x] Нет самостоятельного пользовательского интерфейса удаления; процесс документирован для Ops.
- [x] Проверки включают доступ по старой сессии, связанные выдачи и сохранение результатов.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решение для MVP

Ops сначала получает список активных Activity пользователя. Удаление разрешается только после явного выбора всех Activity для отмены; передача ownership остаётся отдельным процессом. Аккаунт обезличивается в сохранённой строке, чтобы не ломать исторические внешние ключи; вход, сессии и старые email отключаются. Свободный текст независимых Club Network контактов не переписывается автоматически, потому что он принадлежит записи контакта, а не удаляемому профилю. Поведение backup/restore относится к задаче 21.

## Результат

Добавлены Ops GET/POST маршруты `/api/ops/users/:id/profile-deletion`, экран Ops и проверки реального HTTP API/PostgreSQL: 2 сценария. Активные Activity и незавершённые задачи отменяются одной транзакцией; результаты, участие, задачи, transfer history и Club Network связи остаются с подписью `Deleted participant`.
