# 02: Magic link и минимальный профиль

**What to build:** User подтверждает школьную принадлежность и получает доступ Member с минимальным профилем.

**Blocked by:** 01: Первый работающий экран Season

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Magic link отправляется только на точный домен @gso.schule.koeln; проверяется владение адресом, а не только введённая строка.
- [ ] Ссылки одноразовые и ограничены по времени; сессия истекает; новый вход требует нового подтверждения.
- [ ] Для локальной проверки письмо доступно через тестовую доставку, без реальной школьной учётки в seed.
- [ ] Имя и школьная почта обязательны; направление, год и интересы необязательны; профиль редактируется владельцем.
- [ ] User независим от Member/Alumni; утрата школьной принадлежности сама по себе не удаляет аккаунт/историю. Вход Alumni не реализуется.
- [ ] Проверяются secure-cookie/CSRF механизмы, неверные и просроченные ссылки, повторное использование, истечение сессии и запрет чужого редактирования.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решения до реализации

Выбрать auth-библиотеку, доставку email, сроки и ограничения запросов; отдельно записать способ выпуска проверочных идентичностей только для локальных тестов.
