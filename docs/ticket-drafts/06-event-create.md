# 06: Создание Event в подготовке

**What to build:** Member создаёт Event с owner и может готовить его без обещания неподтверждённых условий.

**Blocked by:** 04: Публичные идеи без обязательств

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Собственный Event и Event из Idea создаются без обязательного одобрения; одна Idea допускает несколько реализаций.
- [ ] Категории: Talk, Workshop, Build Night, Study Session, Hackathon, Social, Other.
- [ ] Страница показывает описание, планируемые дату/время/место и состояние подготовки; неизвестные условия допустимы и явно обозначены.
- [ ] Публичная выдача скрывает identities, точную комнату и инструкции доступа; owner/Ops могут редактировать.
- [ ] Текст материалов, GitHub-ссылки и Discord-ссылка редактируются вручную; никаких загрузок и бота.
- [ ] Пока Going не реализован, UI не обещает подтверждённую регистрацию; создание и permissions покрыты проверками.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
