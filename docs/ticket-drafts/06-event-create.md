# 06: Создание Event в подготовке

**What to build:** Member создаёт Event с owner и может готовить его без обещания неподтверждённых условий.

**Blocked by:** 04: Публичные идеи без обязательств

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано локально 2026-09-22; итоговые проверки ниже.

## Acceptance criteria

- [x] Собственный Event и Event из Idea создаются без обязательного одобрения; одна Idea допускает несколько реализаций.
- [x] Категории: Talk, Workshop, Build Night, Study Session, Hackathon, Social, Other.
- [x] Страница показывает описание, планируемые дату/время/место и состояние подготовки; неизвестные условия допустимы и явно обозначены.
- [x] Публичная выдача скрывает identities, точную комнату и инструкции доступа; owner/Ops могут редактировать.
- [x] Текст материалов, GitHub-ссылки и Discord-ссылка редактируются вручную; никаких загрузок и бота.
- [x] Пока Going не реализован, UI не обещает подтверждённую регистрацию; создание и permissions покрыты проверками.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для этой и следующих web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Events хранятся как Activities с отдельными event_details. Создание даёт PLANNING и единственного owner без Ops approval. Idea необязательна; owner/Ops редактируют содержание, но не owner, источник или статус через форму.

Дата, время и общий адрес необязательны и явно предварительны. Время хранится как местное для Europe/Berlin; необязательная дата окончания поддерживает многодневные события. Точная комната, инструкции, Discord и owner доступны только текущим Members. Материалы и repository публичны. Интерфейс DE/EN; авторский текст не переводится.

Проверки: 31 API/CLI-тест, 10 браузерных сценариев, typecheck, lint, build. Standards: общая проверка HTTP(S)-ссылок вынесена для Events/Projects; оставшихся замечаний нет. Spec: замечаний нет. Interested, Room Requests и Going остаются зависимыми задачами.
