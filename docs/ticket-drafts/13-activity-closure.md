# 13: Завершение, отмена и прошедшие

**What to build:** Owner закрывает Activity, урегулирует незавершённые задачи, а её страница сохраняется в прошедших.

**Blocked by:** 08: Вступление в команду Project; 10: Going и повторное подтверждение при переносе; 11: Взять, завершить и освободить Task; 12: Передача Activity Owner

**Status:** реализовано локально 2026-09-22; draft не опубликован в GitHub.

## Acceptance criteria

- [x] Owner завершает или отменяет Event/Project; уход без преемника приводит к отмене.
- [x] При незавершённых задачах есть предупреждение и явное подтверждение; без подтверждения закрытие не применяется.
- [x] После подтверждения OPEN/IN_PROGRESS переходят в CANCELLED с историей, DONE сохраняются.
- [x] Результат закрытия сохраняется целиком, без половинного обновления Activity и Tasks.
- [x] Страница попадает в прошедшие; текст, ссылки и исходная Idea сохраняются; активные CTA не предлагают работу в закрытой Activity.
- [x] Проверяются оба типа Activity, отмена без преемника, предупреждение, задачи и архивное чтение.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.



## Результат

Owner завершает или отменяет Activity со страницы Event/Project. При незавершённых задачах требуется явное подтверждение; сервер без него отвечает 409 и не сохраняет частичных изменений. Закрытие, отмена OPEN/IN_PROGRESS и ожидающей передачи ownership выполняются в одной транзакции с блокировкой Activity. DONE, ответственные за задачи, материалы, Idea и ссылки сохраняются.

Разделы Events/Projects показывают текущие либо прошедшие Activity (`?view=past`). Закрытые страницы сохраняются, рабочие CTA скрыты. Материалы можно дополнять, но перенос закрытого Event запрещён, чтобы не потерять Going. Нельзя создавать и подтверждать новые запросы помещения закрытой Activity. Отмена без преемника снимает активную ответственность, сохраняя исторического owner; после неё Project Leave разрешён.

Проверки: 55 API/CLI-тестов, 17 браузерных сценариев, typecheck, lint и build прошли. Проверены конкурентное создание Task при закрытии, оба типа Activity, оба исхода, отказ без подтверждения и архивное чтение. Standards review и Spec review: замечаний нет.
