# 13: Завершение, отмена и прошедшие

**What to build:** Owner закрывает Activity, урегулирует незавершённые задачи, а её страница сохраняется в прошедших.

**Blocked by:** 08: Вступление в команду Project; 10: Going и повторное подтверждение при переносе; 11: Взять, завершить и освободить Task; 12: Передача Activity Owner

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Owner завершает или отменяет Event/Project; уход без преемника приводит к отмене.
- [ ] При незавершённых задачах есть предупреждение и явное подтверждение; без подтверждения закрытие не применяется.
- [ ] После подтверждения OPEN/IN_PROGRESS переходят в CANCELLED с историей, DONE сохраняются.
- [ ] Результат закрытия сохраняется целиком, без половинного обновления Activity и Tasks.
- [ ] Страница попадает в прошедшие; текст, ссылки и исходная Idea сохраняются; активные CTA не предлагают работу в закрытой Activity.
- [ ] Проверяются оба типа Activity, отмена без преемника, предупреждение, задачи и архивное чтение.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
