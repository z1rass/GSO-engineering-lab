# 11: Взять, завершить и освободить Task

**What to build:** Owner/Ops создают задачи, а Member берёт свободную задачу и сразу начинает работу.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** реализовано локально 2026-09-22; draft не опубликован в GitHub.

## Acceptance criteria

- [x] Owner/Ops создают задачи для обоих типов Activity с описанием и необязательным сроком.
- [x] Take атомарно назначает одного Task Owner и переводит OPEN → IN_PROGRESS.
- [x] Task Owner отмечает выполнение или освобождает незавершённую задачу; она снова свободна и OPEN.
- [x] Owner/Ops управляют задачами Activity; чужой Member не редактирует назначенную другому задачу.
- [x] Take не создаёт Going или Project membership; DONE сохраняет историческое attribution.
- [x] Проверяются конкурентные Take, права, release, completion и отсутствие лишнего участия.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Общий Tasks panel на Event/Project: создание и редактирование Owner/Ops, атомарное взятие свободной задачи, завершение и освобождение ответственным либо Owner/Ops, отмена незавершённой задачи Owner/Ops. DONE сохраняет ответственного. Терминальные задачи нельзя взять или освободить; закрытые Activity запрещают изменения задач.

Visitor видит содержание и статус задачи, Member — также ответственного и доступные действия. Взятие не создаёт Going/Project membership. Тексты интерфейса DE/EN, авторский контент не переводится.

Проверки: 48 API/CLI-тестов, 15 браузерных сценариев, typecheck, lint и build прошли. После Standards review создание задачи также объединено с проверкой прав/статуса в транзакцию с блокировкой Activity; профильные API-тесты и typecheck повторно прошли. Standards и Spec review: оставшихся замечаний нет.
