# 11: Взять, завершить и освободить Task

**What to build:** Owner/Ops создают задачи, а Member берёт свободную задачу и сразу начинает работу.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Owner/Ops создают задачи для обоих типов Activity с описанием и необязательным сроком.
- [ ] Take атомарно назначает одного Task Owner и переводит OPEN → IN_PROGRESS.
- [ ] Task Owner отмечает выполнение или освобождает незавершённую задачу; она снова свободна и OPEN.
- [ ] Owner/Ops управляют задачами Activity; чужой Member не редактирует назначенную другому задачу.
- [ ] Take не создаёт Going или Project membership; DONE сохраняет историческое attribution.
- [ ] Проверяются конкурентные Take, права, release, completion и отсутствие лишнего участия.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
