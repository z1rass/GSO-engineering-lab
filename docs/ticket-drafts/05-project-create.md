# 05: Создание Project с owner

**What to build:** Member создаёт собственный Project или реализацию Idea и сразу становится Activity Owner.

**Blocked by:** 04: Публичные идеи без обязательств

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано и проверено локально 2026-09-22.

## Acceptance criteria

- [x] Создание, список и страница Project работают с целью, описанием, tech stack и ссылками на repository/documentation.
- [x] Creator сразу единственный owner; нет обязательного Ops approval и отдельной глобальной роли организатора.
- [x] Idea необязательна; несколько Projects могут ссылаться на одну Idea без изменения её автора или обязательств.
- [x] Owner/Ops редактируют Project; другие Members не получают эти права; Visitor не получает identity owner.
- [x] Поддерживаются подготовка и переход в работу; вступление команды и завершение поставляются зависимыми задачами.
- [x] Текст материалов и вручную добавленная Discord-ссылка доступны owner для редактирования; приватные инструкции не попадают гостям.
- [x] Проверки проходят через создание, persisted чтение, переход и запреты редактирования.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузерный путь создания, гостевого просмотра, редактирования и начала работы. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Projects хранятся как Activities с отдельными project_details. Создатель становится единственным owner; создание сразу даёт PLANNING без Ops approval. Owner/Ops редактируют содержание и переводят проект в ACTIVE. Idea необязательна, допускает несколько реализаций. Смена owner и source Idea через редактирование недоступна.

Публичны цель, описание, tech stack, repository/documentation, материалы и состояние. Owner, внутренние инструкции и вручную добавленная Discord-ссылка доступны только текущим Members. Авторский текст не переводится; интерфейс DE/EN.

Проверки: 27 API/CLI-тестов, 9 браузерных сценариев, typecheck, lint, build. Standards: повторяющийся hook загрузки данных вынесен в общий модуль, оставшихся замечаний нет. Spec: замечаний нет. Вступление команды, завершение и передача ownership остаются отдельными задачами.
