# 01: Первый работающий экран Season

**What to build:** Visitor открывает локально работающую homepage и видит текущий Season из базы.

**Blocked by:** None (после согласования плана и настройки трекера)

**Status:** реализовано локально; GitHub issue не опубликован. Проверено 2026-09-21.

## Acceptance criteria

- [x] Есть минимальный путь browser → API → PostgreSQL с миграциями и демонстрационным Season; без авторизации и фиктивных данных в UI.
- [x] Homepage объясняет Lab; пустое состояние без текущего Season обработано.
- [x] German по умолчанию, переключение на English и адаптивная вёрстка работают с первого экрана; следующие задачи расширяют эту основу.
- [x] Docker Compose поднимает среду; README описывает запуск; начальный CI проверяет types, lint, tests и build.
- [x] Проверка через публичный API подтверждает чтение Season из базы; браузерная проверка подтверждает отображение.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; границы согласованы пользователем: HTTP API + настоящая PostgreSQL и браузер. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решения до реализации

Выбрать совместимые версии базового стека и минимальные инструменты тестов. Граница тестирования согласована и проверена.


## Результат проверки

Typecheck, lint и build проходят. API: 4 теста с PostgreSQL; браузер: 4 сценария Chromium. Отдельно проверен запуск браузерного сценария с новой пустой тестовой БД. Docker Compose успешно запускает миграции, seed, API и frontend. CI добавлен; удалённый прогон ещё не выполнялся.
