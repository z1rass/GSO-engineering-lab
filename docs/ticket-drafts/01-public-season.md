# 01: Первый работающий экран Season

**What to build:** Visitor открывает локально работающую homepage и видит текущий Season из базы.

**Blocked by:** None (после согласования плана и настройки трекера)

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Есть минимальный путь browser → API → PostgreSQL с миграциями и демонстрационным Season; без авторизации и фиктивных данных в UI.
- [ ] Homepage объясняет Lab; пустое состояние без текущего Season обработано.
- [ ] German по умолчанию, переключение на English и адаптивная вёрстка работают с первого экрана; следующие задачи расширяют эту основу.
- [ ] Docker Compose поднимает среду; README описывает запуск; начальный CI проверяет types, lint, tests и build.
- [ ] Проверка через публичный API подтверждает чтение Season из базы; браузерная проверка подтверждает отображение.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.

## Решения до реализации

Выбрать совместимые версии базового стека и минимальные инструменты тестов. Предлагаемая граница тестирования ещё требует согласования.
