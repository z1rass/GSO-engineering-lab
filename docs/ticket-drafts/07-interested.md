# 07: Interested без регистрации

**What to build:** Member выражает интерес к Idea, Event или Project, не принимая других обязательств.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано локально 2026-09-22.

## Acceptance criteria

- [x] Interested можно поставить и убрать; повторное действие не создаёт дубликаты.
- [x] Интерес к Project не создаёт Project Member, интерес к Event не создаёт Going.
- [x] Ни создание Idea, ни Interested не назначают Activity Owner или Task Owner.
- [x] Счётчики на страницах соответствуют сохранённым отметкам; публичная выдача не раскрывает личности.
- [x] Проверяются все три вида целей, повторные запросы и отсутствие побочных записей участия.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.



## Результат

На страницах Idea, Project и Event доступны счётчик и переключатель Interested для текущего Member; Visitor видит число и ссылку входа. Отметки можно снять и повторить без дубликатов, включая одновременные POST. Публичный API не возвращает личности. DE/EN поясняют отсутствие обязательств; ошибки сохранения позволяют повторить действие.

Отметки хранятся отдельно от участия и ownership. Проверки сравнивают Activity/Idea до и после отметки, а также защищают чужие отметки от удаления. Таблицы Project Member, Going и Task пока отсутствуют; при реализации следующих срезов инвариант независимости нужно сохранить и расширить соответствующие проверки.

Проверки: 34 API/CLI-теста, 11 браузерных сценариев, typecheck, lint, build. После review исправлены URL двух негативных тестов и повторно выполнен interested.test.ts. Standards: замечаний нет. Spec: функциональных замечаний нет; тестовые адреса исправлены.
