# 03: Первичные Ops и обычное назначение

**What to build:** Server admin назначает первых Ops, после чего они могут назначать следующих через сайт.

**Blocked by:** 02: Magic link и минимальный профиль

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] При отсутствии Ops документированная bootstrap-команда назначает подтверждённых school sponsor пользователей.
- [ ] Bootstrap при уже существующих Ops не используется как обычный путь назначения.
- [ ] Действующий Ops назначает/подтверждает новых Ops внутри сайта; изменение роли записывается в журнал.
- [ ] Обычный Member не может назначить роль ни через UI, ни прямым API.
- [ ] Нет отдельного кабинета school sponsor; организационные условия описаны в инструкции.
- [ ] Проверяются bootstrap и последующий нормальный путь с реальным сохранением роли.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
