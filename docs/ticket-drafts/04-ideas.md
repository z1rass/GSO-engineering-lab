# 04: Публичные идеи без обязательств

**What to build:** Member публикует Idea, Visitors читают её, а Ops могут исправить текст.

**Blocked by:** 03: Первичные Ops и обычное назначение

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Идея содержит понятные заголовок и описание, не создаёт Activity и не назначает организационную ответственность.
- [ ] Список и страница идеи доступны Visitors без раскрытия личности автора или email.
- [ ] Создаёт Member, редактирует только Ops, включая запрет редактирования обычному автору.
- [ ] Не реализованные идеи остаются допустимыми; не требуется workflow одобрения или реализации.
- [ ] UI на DE/EN; проверки API покрывают публичную выдачу, создание и матрицу редактирования.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
