# 04: Публичные идеи без обязательств

**What to build:** Member публикует Idea, Visitors читают её, а Ops могут исправить текст.

**Blocked by:** 03: Первичные Ops и обычное назначение

**Status:** локальный ticket draft; в GitHub не опубликован.

**Implementation:** реализовано и проверено локально 2026-09-22.

## Acceptance criteria

- [x] Идея содержит понятные заголовок и описание, не создаёт Activity и не назначает организационную ответственность.
- [x] Список и страница идеи доступны Visitors без раскрытия личности автора или email.
- [x] Создаёт Member, редактирует только Ops, включая запрет редактирования обычному автору.
- [x] Не реализованные идеи остаются допустимыми; не требуется workflow одобрения или реализации.
- [x] UI на DE/EN; проверки API покрывают публичную выдачу, создание и матрицу редактирования.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузерный путь Member → Visitor → Ops. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Публичные список и страница идеи, создание Member и редактирование только Ops. Публичная выдача явно исключает автора; идеи не создают Activity и не назначают ответственность. Интерфейс DE/EN, авторский контент не переводится. Interested остаётся в задаче 07.

Проверки: 22 API/CLI-теста, 8 браузерных сценариев, typecheck, lint, build. Проверены отказы в доступе, валидация, CSRF, пустое состояние, 404, повторная попытка и сохранение текста при ошибке отправки. Standards и Spec review: замечаний нет.
