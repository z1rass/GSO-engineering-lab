# 12: Передача Activity Owner

**What to build:** Текущий owner предлагает передачу, а новый принимает ответственность.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Предложение передачи само по себе не меняет owner.
- [ ] Принятие назначенным получателем завершает передачу; всегда остаётся один действующий owner.
- [ ] Посторонний User не может принять чужое предложение или назначить себя.
- [ ] Ops помогают с управлением передачей; механизм соорганизаторов не вводится.
- [ ] Leave участия не обходит ответственность; уход без преемника использует отмену, поставляемую задачей 13.
- [ ] Проверяются сохранение старого owner до принятия и права получателя после принятия.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
