# 12: Передача Activity Owner

**What to build:** Текущий owner предлагает передачу, а новый принимает ответственность.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** реализовано локально 2026-09-22; draft не опубликован в GitHub.

## Acceptance criteria

- [x] Предложение передачи само по себе не меняет owner.
- [x] Принятие назначенным получателем завершает передачу; всегда остаётся один действующий owner.
- [x] Посторонний User не может принять чужое предложение или назначить себя.
- [x] Ops помогают с управлением передачей; механизм соорганизаторов не вводится.
- [x] Leave участия не обходит ответственность; уход без преемника использует отмену, поставляемую задачей 13.
- [x] Проверяются сохранение старого owner до принятия и права получателя после принятия.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; пользователь подтвердил HTTP API + настоящую PostgreSQL + браузер для web-задач. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.


## Результат

Owner предлагает текущего Member со страницы Event/Project; прежний owner сохраняет ответственность до принятия. Только выбранный получатель принимает. Owner, получатель и Ops могут отменить предложение. Ops помогают управлять предложением, но не назначают себя и не принимают за другого человека. История принятых/отменённых предложений сохраняется; одновременно допускается одно ожидающее предложение.

При принятии owner и статус передачи меняются атомарно. Устаревшее предложение нельзя принять после отмены/замены. Передача не меняет Going, Project membership или назначения Tasks. У прежнего owner пропадают права редактирования, у нового появляются; Leave по-прежнему не освобождает действующего owner. Отмена Activity без преемника остаётся в задаче 13.

Интерфейс DE/EN; Visitor не получает персональные данные передачи. Проверка прав редактирования Event/Project теперь выполняется под блокировкой Activity, чтобы прежний owner не сохранил изменения после конкурентного принятия передачи.

Проверки: 51 API/CLI-тест, 16 браузерных сценариев, typecheck, lint и build прошли. Standards review: замечаний нет. Spec review: гонка с редактированием прежним owner исправлена, повторное ревью подтвердило исправление; открытых замечаний нет.
