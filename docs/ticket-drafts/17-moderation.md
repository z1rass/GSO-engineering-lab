# 17: Скрытие контента и блокировка User

**What to build:** Ops скрывают Idea/Activity или блокируют дальнейшие действия участника с причиной.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** реализовано локально 2026-09-22; draft не опубликован в GitHub.

## Acceptance criteria

- [x] Ops указывают причину скрытия или блокировки; история и данные не уничтожаются.
- [x] Скрытый контент не доступен обычной выдачей и прямой публичной ссылкой/API.
- [x] Заблокированный User не может продолжать изменения через уже открытую сессию или прямой запрос.
- [x] Автор Idea не получает прав редактирования под видом модерации.
- [x] Обращения идут через Discord; нет отдельной системы жалоб.
- [x] Проверки покрывают прямой доступ, действующие сессии и отсутствие уничтожения истории.

## Проверка и границы

Использованы ранее согласованные границы: HTTP API с настоящей изолированной PostgreSQL и браузерный сценарий. Интерфейс DE/EN; авторский контент не переводится.

## Результат

Ops открывают `/ops/moderation`: идеи, активности, участники и последние 100 действий. Скрытие/восстановление и блокировка/снятие блокировки требуют причины; состояние и неизменяемая запись действия сохраняются одной транзакцией. Себя заблокировать нельзя.

Visitors и обычные Members, включая owners, получают 404 для скрытой Idea/Activity и её дочерних ресурсов; Ops сохраняют прямой доступ для разбирательства. Общие списки, Season, homepage и My Activity исключают скрытые данные, ссылки на скрытую исходную Idea убираются. Создать новую Activity из скрытой Idea нельзя. Задачи, участие, ownership, материалы и исходные связи сохраняются и возвращаются после восстановления.

Блокировка проверяется в БД перед каждым защищённым изменением, включая запросы из действующей сессии. Чтение, вход и выход остаются доступны. Профиль объясняет причину и направляет в Discord; обязанности автоматически не отменяются. Отдельных жалоб и сообщений нет.

Проверки: typecheck, lint, build; 67 API/CLI tests и 23 браузерных сценария прошли. Review Standards и Spec — без замечаний.
