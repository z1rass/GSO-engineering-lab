# 17: Скрытие контента и блокировка User

**What to build:** Ops скрывают Idea/Activity или блокируют дальнейшие действия участника с причиной.

**Blocked by:** 05: Создание Project с owner; 06: Создание Event в подготовке

**Status:** draft — ожидает согласования разбиения и выбора трекера; не опубликовано.

## Acceptance criteria

- [ ] Ops указывают причину скрытия или блокировки; история и данные не уничтожаются.
- [ ] Скрытый контент не доступен обычной выдачей и прямой публичной ссылкой/API.
- [ ] Заблокированный User не может продолжать изменения через уже открытую сессию или прямой запрос.
- [ ] Автор Idea не получает прав редактирования под видом модерации.
- [ ] Обращения идут через Discord; нет отдельной системы жалоб.
- [ ] Проверки покрывают прямой доступ, действующие сессии и отсутствие уничтожения истории.

## Проверка и границы

Срез включает необходимые изменения хранения, серверного поведения и пользовательского либо административного интерфейса. Проверять внешний результат, не внутреннее устройство. Предложенная основа: API с изолированной PostgreSQL и небольшое число браузерных сценариев; окончательное согласование границ тестирования ещё ожидается. Все добавленные пользовательские тексты доступны на DE/EN, авторский контент не переводится автоматически.
