# Самостоятельные активности без обязательного одобрения Ops

Платформа должна позволять участникам самостоятельно организовывать инициативы и снижать зависимость от центральной команды. Поэтому активности, которым не нужны школа или её ресурсы, не требуют одобрения Ops: отклонён исходный общий маршрут «proposal → Ops approves» для каждой Activity. Согласование школьной поддержки требуется рассматривать отдельно от готовности участника организовать инициативу; конкретные состояния и ограничения этого процесса ещё предстоит определить.
